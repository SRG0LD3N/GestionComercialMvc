Aplicación web desarrollada con **.NET 8 (ASP.NET Core MVC)** y **Entity Framework Core 8** para la gestión comercial básica. El sistema administra Categorías, Productos y Clientes, utilizando **SQL Server** como base de datos e interfaz estilizada con **Bootstrap 5**.

---

## HERRAMIENTAS UTILIZADAS

- **Framework:** .NET 8 (ASP.NET Core MVC)
- **ORM:** Entity Framework Core v8.0.31
- **Compilación en Vivo:** Razor Runtime Compilation v8.0.31
- **Base de Datos:** SQL Server (LocalDB / Express)
- **Estilos UI:** Bootstrap 5
- **Control de Versiones:** Git y GitHub

---

## MÓDULOS DEL SISTEMA

| Módulo | Descripción |
| :--- | :--- |
| **Categorías** | Clasificación y gestión de las familias de productos. |
| **Productos** | Administración de catálogo, precios y control de stock. |
| **Clientes** | Registro y control de la base de datos de clientes. |

---

## ESTRUCTURA DEL PROYECTO (CRUD)

Cada módulo dispone de sus vistas operativas generadas bajo arquitectura MVC:

| Vista | Descripción |
| :--- | :--- |
| `Index.cshtml` | Listado principal con opciones de navegación. |
| `Create.cshtml` | Formulario para el registro de nuevos elementos. |
| `Edit.cshtml` | Formulario de modificación de registros existentes. |
| `Details.cshtml` | Consulta detallada de la información de un registro. |
| `Delete.cshtml` | Confirmación y eliminación de registros. |
